## Comment target types
- Document comments: inline (anchored) and general
- Task comments: discussion thread

## Permissions (highlights)
- Viewer can create comments on documents (and tasks only if workspace setting allows; default false).
- Edit window is time-limited and varies by role.
- Resolve/reopen thread is Manager+.
