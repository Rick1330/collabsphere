## §12.3 Error Categories

Error codes are grouped into these categories:

1. **Validation** — malformed input
2. **Authentication** — user not authenticated or token invalid
3. **Authorization** — user authenticated but not allowed
4. **Not Found** — resource does not exist (or hidden)
5. **Conflict** — duplicates or concurrent write conflicts
6. **Rate Limiting** — too many requests
7. **Workflow/State** — invalid transitions, locked resources, archived workspace
8. **External Dependency** — storage/email provider down
9. **Internal** — unexpected server failures
