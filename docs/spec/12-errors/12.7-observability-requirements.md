## §12.7 Observability Requirements

- Every error response must log:
  - requestId
  - error code
  - userId (if present)
  - workspaceId (if present)
- Metrics:
  - `api.errors.count` by error code
  - `api.errors.rate` by endpoint
- Alerts:
  - spike in `INTERNAL_ERROR` or `DATABASE_ERROR`
  - spike in `SECURITY` errors (login failed storm)
