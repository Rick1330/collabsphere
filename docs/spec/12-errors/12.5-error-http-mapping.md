## §12.5 Error Mapping to HTTP Status (Rules)

- 400: client error (validation, workflow)
- 401: unauthenticated
- 403: authenticated but forbidden
- 404: not found
- 409: conflict
- 429: rate limit
- 500: internal
- 503: dependency down
