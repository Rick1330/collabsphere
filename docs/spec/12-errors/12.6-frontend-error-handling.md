## §12.6 Frontend Error Handling Patterns (Required)

| Error Code | UI Behavior |
|-----------|-------------|
| `VALIDATION_ERROR` | Inline errors + focus first invalid field |
| `UNAUTHORIZED` / `TOKEN_EXPIRED` | Attempt refresh; if fails redirect to `/login` |
| `NOT_WORKSPACE_MEMBER` | Redirect to `/workspaces` + toast |
| `INSUFFICIENT_ROLE` | Toast: “You don’t have permission” |
| `RATE_LIMITED` | Toast + disable action temporarily (respect Retry-After) |
| `SERVICE_UNAVAILABLE` | Show retry banner + degrade gracefully |
| `INTERNAL_ERROR` | Toast: “Something went wrong” + log requestId |
