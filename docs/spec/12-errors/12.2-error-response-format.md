## §12.2 Error Response Format (Authoritative)

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Title is required",
    "details": [
      { "field": "title", "message": "Title is required", "rule": "isNotEmpty" }
    ],
    "requestId": "req_abc123",
    "timestamp": "2025-07-17T12:00:00Z"
  }
}
```

Rules:
- `code` is required and stable
- `message` is user-facing text (or safe to show)
- `details` optional; include only for validation errors
- `requestId` always included
- never expose stack traces or DB errors directly
