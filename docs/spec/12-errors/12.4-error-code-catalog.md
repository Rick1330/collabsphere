## §12.4 Standard Error Code Catalog (v1)

### §12.4.1 Validation Errors (400)

| Code | Message (example) | When |
|------|-------------------|------|
| `VALIDATION_ERROR` | "Validation failed" | Generic input validation failure |
| `INVALID_EMAIL` | "Invalid email address" | Bad email format |
| `PASSWORD_TOO_WEAK` | "Password does not meet complexity requirements" | Password policy violation |
| `INVALID_CREDENTIALS` | "Invalid credentials" | Current password incorrect or login mismatch |
| `PASSWORD_SAME_AS_CURRENT` | "New password must differ from current password" | Password change uses same value |
| `INVALID_DATE` | "Invalid date value" | Due date in past, bad format |
| `INVALID_ENUM_VALUE` | "Invalid value for field X" | Enum mismatch |
| `INVALID_JSON` | "Malformed JSON request body" | JSON parse error |
| `INVALID_ANCHOR` | "Invalid anchor payload" | Task/doc link anchor invalid |
| `INVALID_MENTION` | "Mentioned user is not valid" | Mention refers to non-member |
| `INVALID_ASSIGNEE` | "Invalid assignee" | Assignee is not a workspace member |
| `INVALID_LABEL` | "Invalid label" | Label violates format or count constraints |
| `INVALID_PARENT` | "Invalid parent" | Parent reference invalid or creates a cycle |
| `INVALID_NEW_OWNER` | "Invalid new owner" | New owner is not an eligible workspace member |
| `INVALID_FILE_TYPE` | "File type not allowed" | MIME not allowlisted |
| `FILE_TOO_LARGE` | "File exceeds maximum size" | Upload > max size |
| `CHECKSUM_MISMATCH` | "File checksum mismatch" | Upload integrity failed |
| `TEMPLATE_CATEGORY_MISMATCH` | "Template category mismatch" | Template category not allowed for workspace type |
| `TEMPLATE_INVALID` | "Template invalid" | Template references missing document template |
| `TEMPLATE_SCHEMA_UNSUPPORTED` | "Template schema unsupported" | Template schema version unsupported |

| `MEMBER_NOT_FOUND` | "Member not found" | Invalid membershipId |

| `FILE_NOT_FOUND` | "File not found" | Missing file |

### §12.4.5 Conflict Errors (409)

| Code | Message | When |
|------|---------|------|
| `EMAIL_ALREADY_EXISTS` | "Email already exists" | Duplicate registration |
| `ACCOUNT_EXISTS_LOCAL` | "Account exists with local auth" | OAuth signup blocked for local-auth email |
| `ACCOUNT_EXISTS_OAUTH` | "Account exists with OAuth provider" | Local signup blocked for OAuth-only email |
| `ACCOUNT_EXISTS_OTHER_PROVIDER` | "Account exists with another provider" | OAuth signup blocked for different provider |
| `WORKSPACE_NAME_CONFLICT` | "Workspace name already used" | Duplicate per-owner name |
| `ALREADY_MEMBER` | "You are already a member" | Accept invite when already member |
| `ATTACHMENT_EXISTS` | "Attachment already exists" | File already attached to target |
| `CONCURRENT_MODIFICATION` | "Resource was modified by another user" | Optional optimistic lock |
| `IDEMPOTENCY_CONFLICT` | "Idempotency key conflict" | Same key with different payload |

### §12.4.7 Workflow / State Errors (400)

| Code | Message | When |
|------|---------|------|
| `INVALID_TRANSITION` | "Invalid status transition" | Task state machine violation |
| `INVALID_STATUS` | "Invalid resource status for this operation" | e.g., submit non-draft doc |
| `CANNOT_DEMOTE_OWNER` | "Cannot demote owner" | Owner must transfer ownership first |
| `CANNOT_REMOVE_OWNER` | "Cannot remove owner" | Owner must transfer ownership first |
| `CANNOT_LEAVE_AS_OWNER` | "Cannot leave as owner" | Owner must transfer ownership first |
| `NO_SUPERVISOR_ASSIGNED` | "Supervisor not assigned" | Academic submission blocked without supervisor |
| `DOCUMENT_EMPTY` | "Document must contain content" | Submitting empty document |
| `NOTE_REQUIRED` | "Feedback note required" | Changes requested without note |
| `FOLDER_NOT_EMPTY` | "Folder is not empty" | Delete folder with children |
| `FILE_NOT_READY` | "File not ready for download/attach" | Pending upload |
| `UPLOAD_NOT_FOUND_IN_STORAGE` | "Upload not found in storage" | Complete upload but object missing |
| `WORKSPACE_MISMATCH` | "Workspace mismatch" | Cross-workspace resource linkage |
| `WORKSPACE_LIMIT_REACHED` | "Workspace limit reached" | Too many workspaces |
| `WORKSPACE_MEMBER_LIMIT_REACHED` | "Workspace member limit reached" | Too many members |
| `WORKSPACE_STORAGE_LIMIT_REACHED` | "Workspace storage limit reached" | Upload exceeds workspace storage quota |
| `TASK_LIMIT_REACHED` | "Task limit reached" | Too many tasks |
| `DOCUMENT_LIMIT_REACHED` | "Document limit reached" | Too many documents |
| `INVITATION_EXPIRED` | "Invitation expired" | Token expired |
| `INVITATION_ALREADY_USED` | "Invitation already used" | Already accepted |
| `TOKEN_ALREADY_USED` | "Token already used" | Verification/reset token reused |
| `TOKEN_EXPIRED` | "Token expired" | Verification/reset expired |

> **Per-endpoint HTTP overrides for `POST /api/v1/auth/verify-email`:** `TOKEN_INVALID` returns `400` (not the catalog default `401`); `TOKEN_EXPIRED` returns `410 Gone` (not `400`). These overrides are intentional and documented in `apps/api/src/auth/auth.service.ts` (`createVerifyEmailService`). Cross-reference `docs/agent-ref/api/auth-endpoints.md § Verify Email`.
