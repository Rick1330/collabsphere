# §12 — Error Taxonomy & Standard Error Codes

## §12.1 Overview

CollabSphere uses a consistent, machine-readable error taxonomy across all APIs. This enables:

- predictable frontend error handling
- reliable testing (assert on error codes)
- consistent observability (metrics by error code)
- safer API evolution

All errors follow the envelope defined in §9.4.
