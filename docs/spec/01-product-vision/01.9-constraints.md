## §1.9 Constraints

| Constraint | Description | Impact |
|------------|-------------|--------|
| **Team size** | 3 core developers initially, growing with contributors | Prioritize modular architecture for parallel work |
| **Timeline** | v1 target: 4-6 months | Aggressive scope control, no gold-plating |
| **Budget** | Open-source project, no paid services initially | Use free tiers (Vercel, Supabase/self-hosted PG, Resend) |
| **Infrastructure** | Standard cloud hosting (no exotic services) | Docker + single VPS or free-tier cloud |
| **Compliance** | FERPA awareness (student data), GDPR readiness | Privacy-by-design, data export capability |
