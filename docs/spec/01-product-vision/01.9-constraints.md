## §1.9 Constraints

| Constraint | Description | Impact |
|------------|-------------|--------|
| **Team size** | 3 core developers initially, growing with contributors | Prioritize modular architecture for parallel work |
| **Timeline** | v1 target: 4-6 months | Aggressive scope control, no gold-plating |
| **Budget** | Open-source project; minimize recurring spend, but allow managed hosting where it materially reduces ops risk | Prefer low-cost/free tiers in local and early environments, keep production spend explicit, and preserve portability |
| **Infrastructure** | Standard cloud hosting with portable containers | Use Vercel for `web` and a managed container host for backend services, while keeping OCI-compatible images so an alternate host remains viable |
| **Compliance** | FERPA awareness (student data), GDPR readiness | Privacy-by-design, data export capability |
