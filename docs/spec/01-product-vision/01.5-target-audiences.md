## §1.5 Target Audiences

### §1.5.1 Primary: Professional Software Teams (3-30 people)

Small to mid-size software development teams that need a unified workspace for documentation, task tracking, and collaboration. These teams currently use 3-5 separate tools and want to consolidate without sacrificing functionality.

**Characteristics:**
- Technical comfort: High
- Usage frequency: Daily, all-day
- Device: Desktop primary (laptop/monitor)
- Key pain: Context switching between tools, lost project history
- Willingness to pay: Yes (future SaaS model)

### §1.5.2 Primary: Academic Project Teams (2-8 students + supervisor)

University students working on group projects (senior projects, thesis work, lab assignments) who need a structured workspace that supports academic workflows including supervisor oversight and submission/review cycles.

**Characteristics:**
- Technical comfort: Moderate to High (CS/Engineering students)
- Usage frequency: Daily during project periods
- Device: Laptop primary
- Key pain: Tool fragmentation, version conflicts, supervisor communication
- Willingness to pay: No (free tier essential)

### §1.5.3 Secondary: Open Source Project Teams

Open source maintainers and contributors who need lightweight project documentation and task coordination without enterprise complexity.

### §1.5.4 Secondary: Freelancers and Small Agencies

Individual freelancers or small teams (2-5 people) who need a single tool for client project management, documentation, and task tracking.
