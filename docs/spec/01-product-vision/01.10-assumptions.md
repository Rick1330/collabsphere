## §1.10 Assumptions

These assumptions underpin the entire plan. If any prove false, the plan must be revisited.

1. **Yjs + Hocuspocus will handle real-time collaboration** — we will not build a custom CRDT implementation.
2. **PostgreSQL full-text search is sufficient for v1** — we will not need Elasticsearch until v2+.
3. **Email delivery via Resend or similar free-tier service** is sufficient for v1 volume.
4. **All users have a modern browser** with WebSocket support — no IE11 or legacy browser support.
5. **The primary interaction device is a laptop/desktop** — mobile is view-only at best for v1.
6. **Contributors will join after v1 launch** — architecture must support onboarding new developers.
7. **No monetization in v1** — no billing, payment, or subscription logic needed.
