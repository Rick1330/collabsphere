## §1.7 Release Strategy & Scope Boundaries

### §1.7.1 v1.0 — "Foundation" (This Build)

Everything needed for teams to use CollabSphere as their primary workspace.

**P0 — Critical (Must Have for Launch):**

- User registration and authentication (email/password + Google OAuth)
- Workspace creation with workspace type selection (Professional / Academic)
- Workspace member management (invite, remove, change role)
- Role-based access control (Owner, Admin, Manager, Member, Viewer)
- Rich-text document editor with real-time collaboration (Tiptap + Yjs)
- Document CRUD with hierarchical folder structure
- Kanban task board with drag-and-drop
- Task CRUD with assignment, priority, due date, status
- Comment threads on documents and tasks
- In-app notification system
- Activity feed per workspace
- App shell (sidebar, top navigation, workspace switcher)
- Command palette (Cmd+K / Ctrl+K)
- Dark mode / light mode / system theme
- Built-in workspace and document templates
- Basic full-text search

**P1 — High (Essential for Usability):**

- Email notifications (instant + digest)
- Document version history with restore
- Task list view (table/sortable)
- Notification preferences (per-type toggles)
- Profile management (name, avatar, bio)
- Workspace settings (name, description, danger zone)
- Academic mode: submission/review workflow for documents
- Collaborative cursors and presence indicators
- Document export (PDF, Markdown)
- Keyboard shortcuts for common actions
- Responsive layout (tablet-friendly, mobile-viewable)

**P2 — Medium (Important, Not Launch-Blocking):**

- Workspace analytics dashboard (task completion, member activity)
- Document outline / table of contents panel
- Slash commands in editor (type `/` for block insertion)
- Task labels and filtering
- Inline comments on documents (select text → comment)
- Comment resolution (mark as resolved)
- Favorites / pinned items in sidebar
- Recently viewed items
- File attachments on documents and tasks
- @Mentions in documents and comments

**P3 — Low (Post-Launch Enhancement):**

- Custom templates (user-created from existing documents)
- Task calendar view
- Task dependencies (blocked by)
- Bulk task actions
- Exportable project reports (PDF summary)
- Advanced search with filters (by type, date, author)
- Workspace archival
- Read receipts on documents

### §1.7.2 v1.1 — "Polish" (Fast-Follow, Months 6-9)

- Suggestion mode in editor (track changes)
- Task timeline view
- Advanced workspace analytics
- Template marketplace (community-shared templates)
- Notification digest emails (daily/weekly summary)
- Import from Markdown files
- Document locking mechanism
- Subtask checklists within tasks
- Workspace-level announcement system

### §1.7.3 v2.0+ — "Platform" (Future, Months 9-18)

- Webhook system (outbound event hooks for integrations)
- GitHub integration (link repositories, show commit activity)
- Slack integration (post activity to channels)
- Two-Factor Authentication (TOTP)
- Public API for external developers
- Import utilities (Trello JSON, Notion export)
- Offline mode with sync
- Mobile native app (React Native)
- SSO / SAML for enterprise
- Advanced RBAC (custom roles, fine-grained permissions)
- Plugin / extension system
- AI-powered features (writing assistant, task suggestions)
- Multi-language / internationalization (i18n)

### §1.7.4 Explicitly Out of Scope (No Version Planned)

- Video/audio calling (use Zoom/Meet)
- Direct messaging / chat between users (use existing chat tools)
- Code editing / IDE features (use VS Code)
- Billing / payment processing (free for foreseeable future)
- White-labeling / custom branding per workspace
- On-premise deployment packaging
