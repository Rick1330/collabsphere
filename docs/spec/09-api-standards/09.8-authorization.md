## §9.8 Authorization Standards (RBAC)

### §9.8.1 Workspace Authorization
All workspace routes must validate:
1. user is authenticated
2. workspace exists and not deleted
3. user is active member of workspace
4. user has minimum role required for action
5. workspace not archived (for write actions)

Return codes:
- 401: not authenticated
- 403: not a workspace member OR insufficient role
- 404: workspace not found (if you prefer not to reveal existence to non-members, you can return 404 for non-members; choose one consistent strategy)

**v1 recommendation:** return `403 NOT_WORKSPACE_MEMBER` for clarity in authenticated contexts.
