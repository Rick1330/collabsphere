## §9.5 Pagination Standards

### §9.5.1 Default Pagination
- Default page size: 25
- Allowed page sizes: 10, 25, 50, 100
- Max page size: 100
- Page index is 1-based

### §9.5.2 Query Parameters
- `page`
- `pageSize`
- `sortBy`
- `sortOrder=asc|desc`
