## §9.2 API Principles

1. **Consistency over cleverness**  
   Every endpoint uses the same response envelope, error format, pagination shape, and auth pattern.

2. **Workspace isolation by design**  
   All workspace-owned resources are accessed through workspace-scoped routes:
   - `/api/v1/workspaces/:workspaceId/...`

3. **No “hidden state”**  
   Backend must not infer workspace context implicitly. `workspaceId` is explicit in URL and validated.

4. **Secure defaults**  
   - deny by default
   - explicit RBAC guards
   - never leak sensitive data in errors

5. **Backward compatible evolution**  
   - add fields, don’t rename
   - new endpoints, don’t break old ones
   - version APIs when breaking changes unavoidable
