## §9.11 Response Field Naming

- JSON fields use `camelCase`
- DB fields use `snake_case`
- Enums in API are uppercase for roles, lowercase for statuses (choose one consistently)

**v1 recommendation:**
- roles: uppercase (`OWNER`, `ADMIN`)
- statuses: lowercase (`in_progress`)
- types: lowercase (`professional`)
