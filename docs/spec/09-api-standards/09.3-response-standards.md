## §9.3 Request/Response Standards

### §9.3.1 Success Envelope (Single Resource)

```json
{
  "data": {
    "resource": { }
  },
  "meta": {
    "requestId": "req_abc123"
  }
}
```

### §9.3.2 Success Envelope (List Resource)

```json
{
  "data": {
    "items": [ ],
    "total": 120
  },
  "meta": {
    "requestId": "req_abc123",
    "pagination": {
      "page": 1,
      "pageSize": 25,
      "totalItems": 120,
      "totalPages": 5,
      "hasNextPage": true,
      "hasPreviousPage": false
    }
  }
}
```

### §9.3.3 Minimal Success Envelope (Action)

```json
{
  "data": {
    "message": "OK"
  },
  "meta": {
    "requestId": "req_abc123"
  }
}
```
