## §9.9 Rate Limiting Standards

Minimum baseline:
- Read endpoints: 120/min/user
- Write endpoints: 30/min/user
- Auth endpoints: stricter (see §5.1)

Return:
- `429 RATE_LIMITED`

Response header:
- `Retry-After: <seconds>`
