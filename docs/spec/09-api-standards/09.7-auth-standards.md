## §9.7 Authentication Standards

### §9.7.1 Bearer Token for Access Token
- Header:
  - `Authorization: Bearer <accessToken>`

### §9.7.2 Refresh Token
- Stored as httpOnly cookie:
  - `refresh_token=...`

Refresh endpoint:
- `POST /api/v1/auth/refresh`
