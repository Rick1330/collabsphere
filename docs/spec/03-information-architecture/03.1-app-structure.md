# §3 — Information Architecture & Navigation

## §3.1 Application Structure Overview

CollabSphere is organized into four major interface contexts, each with its own navigation structure and layout behavior.

```
┌─────────────────────────────────────────────────────────────┐
│                    CollabSphere Application                  │
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │  Public       │  │  Global      │  │  Workspace       │  │
│  │  Context      │  │  Context     │  │  Context         │  │
│  │              │  │              │  │                  │  │
│  │  • Landing   │  │  • Dashboard │  │  • Documents     │  │
│  │  • Login     │  │  • Workspace │  │  • Tasks         │  │
│  │  • Register  │  │    List      │  │  • Members       │  │
│  │  • Forgot PW │  │  • Notifs    │  │  • Activity      │  │
│  │  • Reset PW  │  │  • Settings  │  │  • Files         │  │
│  │  • Verify    │  │  • Profile   │  │  • Analytics     │  │
│  │    Email     │  │              │  │  • Settings      │  │
│  └──────────────┘  └──────────────┘  └──────────────────┘  │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐   │

```
