## §3.9 Theme System

### §3.9.1 Theme Options

| Option | Behavior |
|--------|----------|
| **Light** | Light background, dark text. Default for new users. |
| **Dark** | Dark background, light text. Reduced eye strain. |
| **System** | Follows the operating system preference (`prefers-color-scheme` media query). Automatically switches between light and dark. |

### §3.9.2 Theme Persistence

- Theme preference is stored in the `users` table (`theme_preference` column: `'light'`, `'dark'`, `'system'`)
- On page load, the theme is applied before first paint to prevent flash of wrong theme (FOUC)
- Theme can be changed via: Settings > Appearance page, User avatar dropdown toggle, Command palette ("toggle dark mode")
- Theme change is applied instantly (no page reload)
- CSS implementation uses CSS custom properties (variables) on the `:root` / `[data-theme="dark"]` selector

### §3.9.3 Color Palette Structure

```css
/* Light theme (default) */
:root {
  --color-bg-primary: #ffffff;
  --color-bg-secondary: #f9fafb;
  --color-bg-tertiary: #f3f4f6;
  --color-text-primary: #111827;
  --color-text-secondary: #6b7280;
  --color-text-tertiary: #9ca3af;
  --color-border: #e5e7eb;
  --color-accent: #3b82f6;        /* Blue-500 */
  --color-accent-hover: #2563eb;  /* Blue-600 */
  --color-success: #10b981;       /* Green-500 */
  --color-warning: #f59e0b;       /* Amber-500 */
  --color-error: #ef4444;         /* Red-500 */
  --color-info: #3b82f6;          /* Blue-500 */
}

/* Dark theme */
[data-theme="dark"] {
  --color-bg-primary: #0f172a;
  --color-bg-secondary: #1e293b;
  --color-bg-tertiary: #334155;
  --color-text-primary: #f8fafc;
  --color-text-secondary: #94a3b8;
  --color-text-tertiary: #64748b;
  --color-border: #334155;
  --color-accent: #60a5fa;        /* Blue-400 */
  --color-accent-hover: #93bbfd;  /* Blue-300 */
  /* Success, warning, error, info: slightly adjusted for dark bg contrast */
}
```

Note: Actual colors will be implemented via Tailwind CSS configuration. The above shows the variable structure. All UI components must use these variables exclusively — never hardcode colors.
