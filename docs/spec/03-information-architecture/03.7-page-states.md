## §3.7 Page States

Every page and data-loading section in CollabSphere must handle exactly four states. No exceptions.

### §3.7.1 State Definitions

| State | When | Visual Pattern |
|-------|------|---------------|
| **Loading** | Data is being fetched from the API | Skeleton screens matching the content layout. Never a spinner alone. Skeleton should mimic the shape of the actual content so the page doesn't "jump" when data loads. |
| **Empty** | Data loaded successfully but the result set is empty | Illustration + descriptive message + primary call-to-action button. The message should explain what would appear here and guide the user to create their first item. |
| **Error** | Data fetch failed (network error, server error, etc.) | Error icon + message + retry button. Include `requestId` in a "Report Issue" link for debugging. Never show stack traces or technical details. |
| **Loaded** | Data loaded successfully with results | Normal content display |

### §3.7.3 Error State Patterns

| Error Type | HTTP Status | User Message | Action Available |
|------------|------------|--------------|----------------|
| Network offline | — | "You're offline. Please check your internet connection." | [Retry] |
| Server error | 500 | "Something went wrong. Please try again." | [Retry] + "If the problem persists, contact support. (Request ID: req_xxx)" |
| Not found | 404 | "This page doesn't exist or has been moved." | [Go to Dashboard] |
| Not authorized | 403 | "You don't have permission to access this page." | [Go to Dashboard] |
| Session expired | 401 | "Your session has expired. Please sign in again." | [Sign In] (redirect to login) |
| Rate limited | 429 | "You're making requests too quickly. Please wait a moment." | Auto-retry after cooldown, button disabled with countdown |
| Workspace not found | 404 | "This workspace doesn't exist or you're not a member." | [Go to Workspaces] |
| Document not found | 404 | "This document doesn't exist or has been deleted." | [Go to Documents] |
