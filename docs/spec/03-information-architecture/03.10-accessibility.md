## §3.10 Accessibility Standards

### §3.10.1 Target Compliance

**WCAG 2.1 Level AA** — This is the target for all CollabSphere UI.

### §3.10.2 Specific Requirements

| Category | Requirement | Implementation |
|----------|-------------|----------------|
| **Color Contrast** | Minimum 4.5:1 for normal text, 3:1 for large text (18px+ or 14px+ bold) | Validate all color combinations in both light and dark themes |
| **Keyboard Navigation** | All interactive elements must be reachable and operable via keyboard alone | Tab order follows visual order. Custom components implement proper `tabindex`, `role`, and keyboard event handlers. |
| **Focus Indicators** | Visible focus ring on all interactive elements | 2px solid outline using `--color-accent` with 2px offset. Never `outline: none` without replacement. |
| **Screen Reader** | All content must be accessible to screen readers | Semantic HTML (`<nav>`, `<main>`, `<article>`, `<section>`, `<button>`, `<heading>`). ARIA labels on icon-only buttons. ARIA live regions for dynamic content updates. |
| **Skip Navigation** | "Skip to main content" link at top of page | Visually hidden until focused. Links to `<main>` element. |
| **Images** | All images must have alt text | Decorative images: `alt=""`. Meaningful images: descriptive alt text. User avatars: `alt="[Name]'s avatar"`. |
| **Forms** | All form inputs must have associated labels | Visible `<label>` elements with `htmlFor`. Error messages linked via `aria-describedby`. Required fields marked with `aria-required`. |
| **Motion** | Respect `prefers-reduced-motion` | All animations and transitions check this media query. If reduced motion is preferred, transitions are instant (duration: 0ms) and animations are disabled. |
| **Color Independence** | Information must not be conveyed by color alone | Task priorities use color AND icon/shape. Status indicators use color AND text label. Error states use color AND icon AND text. |
| **Drag and Drop** | Alternative to drag-and-drop must exist | Kanban board: keyboard shortcut `M` to move a focused task, then arrow keys to select target column, Enter to confirm. Toolbar button alternative for reordering documents. |
| **Announcements** | Screen reader announcements for dynamic updates | On drag completion: "Task [title] moved to [column]". On notification received: "New notification: [title]". On save: "Document saved". Use `aria-live="polite"` regions. |

### §3.10.3 Accessible Component Patterns

| Component | Required ARIA | Keyboard |
|-----------|-------------|----------|
| **Sidebar Navigation** | `<nav aria-label="Workspace navigation">` | Tab through items, Enter to navigate |
| **Dropdown Menu** | `role="menu"`, `role="menuitem"`, `aria-expanded` | Enter/Space to open, arrow keys to navigate, Esc to close |
| **Modal / Dialog** | `role="dialog"`, `aria-modal="true"`, `aria-labelledby` | Focus trapped inside modal, Esc to close, focus returns to trigger on close |
| **Notification Badge** | `aria-label="3 unread notifications"` | — |
| **Task Card** | `<article aria-label="Task: [title], Priority: [priority], Assigned to: [name]">` | Tab to focus, Enter to open, M to move |
| **Tab Panel** | `role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-selected` | Arrow keys between tabs, Tab into panel content |
| **Toast / Alert** | `role="alert"` or `role="status"`, `aria-live="polite"` | Auto-dismiss after 5s, Esc to dismiss early, focus not stolen |
| **Search Input** | `role="combobox"`, `aria-expanded`, `aria-activedescendant` | Type to search, arrow keys to navigate results, Enter to select |
| **Command Palette** | `role="dialog"` + `role="combobox"` | Same as search + Esc to close |
