## §3.4 Breadcrumbs

Breadcrumbs are displayed below the top navigation bar on all pages except the dashboard and landing page. They provide navigational context and allow quick traversal up the hierarchy.

### Breadcrumb Patterns

| Context | Breadcrumb |
|---------|-----------|
| Dashboard | *(no breadcrumb)* |
| Workspace List | Workspaces |
| Create Workspace | Workspaces / New Workspace |
| Workspace Home | Workspaces / Project Alpha |
| Document List | Workspaces / Project Alpha / Documents |
| Document Editor | Workspaces / Project Alpha / Documents / Chapter 1 / Introduction |
| Task Board | Workspaces / Project Alpha / Tasks |
| Task Detail | Workspaces / Project Alpha / Tasks / Implement Login Page |
| Members | Workspaces / Project Alpha / Members |
| Workspace Settings | Workspaces / Project Alpha / Settings |
| Notification Center | Notifications |
| User Settings | Settings / Profile |
| Admin Dashboard | Admin |
| Admin Users | Admin / Users |
| Admin User Detail | Admin / Users / jane@example.com |

### Breadcrumb Rules

1. Every segment except the last (current page) is a clickable link
2. The last segment is plain text (not linked) — it represents the current page
3. Workspace name is always shown as the second segment when in workspace context
4. Document breadcrumbs follow the folder hierarchy (e.g., Chapter 1 / Introduction)
5. Long names are truncated with ellipsis (`...`) at 30 characters
6. On mobile (<768px), only the last 2 segments are shown with a `...` prefix
