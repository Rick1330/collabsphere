## §3.3 Navigation Components

### §3.3.1 Top Navigation Bar (Always Visible When Authenticated)

The top navigation bar is fixed at the top of the viewport across all authenticated pages.

```
┌──────────────────────────────────────────────────────────────────────────┐
│  [☰] [Logo CollabSphere]  [Workspace Switcher ▾]    [── Search ──]  🔔(3) [👤▾] │
└──────────────────────────────────────────────────────────────────────────┘
```

| Element | Position | Behavior |
|---------|----------|----------|
| **Hamburger Menu** `[☰]` | Far left | Toggles left sidebar collapse on desktop. Opens slide-over sidebar on mobile. Hidden on desktop if sidebar is always visible. |
| **Logo** | Left | Links to `/dashboard`. Always visible. Clicking while inside a workspace navigates to global dashboard. |
| **Workspace Switcher** | Left of center | Dropdown showing all workspaces user belongs to, sorted by last accessed. Shows current workspace name + icon when inside a workspace. Shows "Select Workspace" on global pages. Includes "Create Workspace" option at bottom of list. Keyboard shortcut: `Ctrl+W` / `Cmd+W`. |
| **Search Bar** | Center | Global search input. Keyboard shortcut: `Cmd+K` / `Ctrl+K` opens command palette (which includes search). When inside a workspace, defaults to workspace-scoped search. Toggle for "All workspaces" search. Placeholder text: "Search or press ⌘K for commands..." |
| **Notification Bell** `🔔` | Right | Shows unread count badge (red circle, white text). Max display: "99+". Clicking opens notification dropdown (last 10 items). "View All" link navigates to `/notifications`. Badge hidden when count is 0. |
| **User Avatar** `[👤▾]` | Far right | Circular avatar image (or initials if no avatar). Clicking opens dropdown menu with: Display name, Email, Role badge, Divider, Dashboard link, Settings link, Admin Dashboard (if Platform Admin), Divider, Theme toggle (☀️/🌙), Divider, Sign Out. |

Visible on global pages (dashboard, workspace list, notifications, settings). Not visible on public pages.

```
┌─────────────────────────┐
│  CollabSphere            │
│  ─────────────────────── │
│  🏠 Dashboard            │
│  📁 Workspaces           │
│  🔔 Notifications        │
│  ─────────────────────── │
│  RECENT WORKSPACES       │
│  ├── 🟢 Project Alpha    │
│  ├── 🟡 Senior Project   │
│  └── ⚪ Side Quest       │
│  ─────────────────────── │
│  ⚙️ Settings             │
│  ─────────────────────── │
│  [+ New Workspace]       │
└─────────────────────────┘
```

| Element | Route | Visible To |
|---------|-------|-----------|
| Dashboard | `/dashboard` | All authenticated users |
| Workspaces | `/workspaces` | All authenticated users |
| Notifications | `/notifications` | All authenticated users |
| Recent Workspaces | `/w/:id` (direct link) | All authenticated users, shows last 5 accessed |
| Settings | `/settings/profile` | All authenticated users |
| + New Workspace | `/workspaces/new` | All authenticated users |

│  👥 Members              │
│  📊 Activity             │

| Element | Route | Visible To | Notes |
|---------|-------|-----------|-------|

### §3.3.4 Sidebar Behavior

| Breakpoint | Behavior |
|-----------|----------|
| **Desktop (≥1280px)** | Sidebar always visible, width 260px. Collapsible to 60px icon-only mode via hamburger or keyboard shortcut `Cmd+B` / `Ctrl+B`. Collapsed state persisted in localStorage. |
| **Tablet (768–1279px)** | Sidebar collapsed by default (icon-only 60px). Expands on hamburger click as overlay. Clicking outside closes it. |
| **Mobile (<768px)** | Sidebar hidden by default. Hamburger opens full-screen slide-over. Swipe right from left edge also opens it. Selecting a nav item closes the sidebar. |
