## §3.2 Complete Route Map

### §3.2.1 Public Routes (No Authentication Required)

| Route | Page Name | Component | Description |
|-------|-----------|-----------|-------------|
| `/` | Landing Page | `LandingPage` | Marketing/info page with CTAs to register and login |
| `/login` | Login | `LoginPage` | Email/password form + Google OAuth button |
| `/register` | Register | `RegisterPage` | Registration form with email verification |
| `/forgot-password` | Forgot Password | `ForgotPasswordPage` | Email input to trigger password reset |
| `/reset-password/:token` | Reset Password | `ResetPasswordPage` | New password form, validates token |
| `/verify-email/:token` | Email Verification | `VerifyEmailPage` | Confirms email address, redirects to login |
| `/invite/:token` | Accept Invitation | `AcceptInvitePage` | Accept workspace invitation (redirects to login/register if needed) |

### §3.2.2 Global Routes (Authenticated, No Workspace Context)

| Route | Page Name | Component | Layout | Description |
|-------|-----------|-----------|--------|-------------|
| `/dashboard` | Dashboard | `DashboardPage` | AppShell (global sidebar) | Overview: recent workspaces, my tasks, recent activity |
| `/workspaces` | Workspace List | `WorkspaceListPage` | AppShell | All workspaces user belongs to |
| `/workspaces/new` | Create Workspace | `CreateWorkspacePage` | AppShell | Workspace creation wizard with type + template selection |
| `/notifications` | Notification Center | `NotificationsPage` | AppShell | Full notification history with filters |
| `/settings` | Settings Layout | `SettingsLayout` | AppShell | Parent layout for settings pages |
| `/settings/profile` | Profile Settings | `ProfileSettingsPage` | Settings | Name, email, avatar, bio |
| `/settings/password` | Password Settings | `PasswordSettingsPage` | Settings | Change password |
| `/settings/notifications` | Notification Preferences | `NotificationPrefsPage` | Settings | Per-type notification toggles |
| `/settings/appearance` | Appearance | `AppearancePage` | Settings | Theme selection (light/dark/system) |

### §3.2.3 Workspace Routes (Authenticated + Workspace Membership Required)

| Route | Page Name | Component | Description |
|-------|-----------|-----------|-------------|
| `/w/:workspaceId` | Workspace Home | `WorkspaceHomePage` | Workspace dashboard with summary cards |
| `/w/:workspaceId/documents` | Document List | `DocumentListPage` | All documents with folder tree sidebar |
| `/w/:workspaceId/documents/new` | New Document | `NewDocumentPage` | Create document (title + template selection) |
| `/w/:workspaceId/documents/:documentId` | Document Editor | `DocumentEditorPage` | Full Tiptap editor with collaboration |
| `/w/:workspaceId/documents/:documentId/history` | Version History | `VersionHistoryPage` | List of versions with diff view |
| `/w/:workspaceId/tasks` | Task Board | `TaskBoardPage` | Kanban board (default view) |
| `/w/:workspaceId/tasks/list` | Task List | `TaskListPage` | Table/list view with sorting and filtering |
| `/w/:workspaceId/tasks/:taskId` | Task Detail | `TaskDetailPage` | Full task detail (can also be slide-over panel) |
| `/w/:workspaceId/members` | Members | `MembersPage` | Member list with role management |
| `/w/:workspaceId/activity` | Activity Feed | `ActivityFeedPage` | Chronological workspace activity log |
| `/w/:workspaceId/files` | Files | `FilesPage` | All uploaded files with preview |
| `/w/:workspaceId/analytics` | Analytics | `AnalyticsPage` | Workspace analytics dashboard (Manager+) |
| `/w/:workspaceId/settings` | Workspace Settings | `WorkspaceSettingsPage` | Name, description, type, danger zone (Admin+) |
| `/w/:workspaceId/settings/members` | Member Management | `MemberManagementPage` | Detailed member/invite management (Admin+) |
| `/w/:workspaceId/templates` | Templates | `TemplatesPage` | Browse and manage workspace templates |

### §3.2.4 Admin Routes (Authenticated + Platform Admin Role Required)

| Route | Page Name | Component | Description |
|-------|-----------|-----------|-------------|
| `/admin` | Admin Dashboard | `AdminDashboardPage` | System overview: user counts, workspace counts, storage |
| `/admin/users` | User Management | `AdminUsersPage` | Search, list, manage all platform users |
| `/admin/users/:userId` | User Detail | `AdminUserDetailPage` | Single user info, workspaces, activity, actions |
| `/admin/workspaces` | Workspace Management | `AdminWorkspacesPage` | All workspaces with admin actions |
| `/admin/audit` | Audit Log | `AdminAuditPage` | Security event log (logins, permission changes, exports) |
| `/admin/settings` | System Settings | `AdminSettingsPage` | Platform-wide configuration |
