## §3.5 Command Palette

The command palette is a modal search/action interface accessible from any page via `Cmd+K` (macOS) or `Ctrl+K` (Windows/Linux).

### Appearance

```
┌─────────────────────────────────────────────────────┐
│  🔍 Type a command or search...                      │
│─────────────────────────────────────────────────────│
│  RECENT                                              │
│  📄 Introduction — Project Alpha                     │
│  ✅ Fix login bug — Project Alpha                    │
│  📄 API Design — Client Project                      │
│                                                      │
│  ACTIONS                                             │
│  [+] Create new document                             │
│  [+] Create new task                                 │
│  [+] Create new workspace                            │
│  ⚙️  Go to settings                                  │
│  🌙  Toggle dark mode                                │
│                                                      │
│  NAVIGATION                                          │
│  📦 Project Alpha                                    │
│  📦 Senior Project                                   │
│  📦 Client Project                                   │
│                                                      │
│  ────────────────────────────────────────────────── │
│  ↑↓ Navigate   ↵ Select   esc Close                 │
└─────────────────────────────────────────────────────┘
```

### Behavior

| Aspect | Detail |
|--------|--------|
| **Trigger** | `Cmd+K` / `Ctrl+K` from any page. Also clickable via the search bar in the top nav. |
| **Search scope** | When inside a workspace: searches documents, tasks, and members in that workspace. Prefix with `>` for global commands. When on global pages: searches across all workspaces. |
| **Debounce** | Search triggers after 200ms of no typing |
| **Results** | Grouped by type: Recent, Documents, Tasks, Workspaces, Members, Actions. Max 5 results per group. |
| **Keyboard navigation** | `↑` `↓` to navigate results. `Enter` to select. `Esc` to close. `Tab` to cycle through groups. |
| **No results** | Show "No results found for '[query]'" with suggestion to try different keywords |
| **Actions available** | Create document, Create task, Create workspace, Go to settings, Go to notifications, Toggle dark mode, Go to admin (if admin), Copy current page URL |

### Available Commands

| Command | Keyword Triggers | Action |
|---------|-----------------|--------|
| Create Document | "new doc", "create document" | Opens new document dialog in current workspace |
| Create Task | "new task", "create task" | Opens new task dialog in current workspace |
| Create Workspace | "new workspace", "create workspace" | Navigates to `/workspaces/new` |
| Go to Dashboard | "dashboard", "home" | Navigates to `/dashboard` |
| Go to Settings | "settings", "preferences" | Navigates to `/settings/profile` |
| Go to Notifications | "notifications", "alerts" | Navigates to `/notifications` |
| Toggle Dark Mode | "dark mode", "light mode", "theme" | Toggles theme |
| Go to Admin | "admin" | Navigates to `/admin` (admin only) |
| Sign Out | "sign out", "logout", "log out" | Signs out the user |
