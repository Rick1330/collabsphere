## §3.6 Keyboard Shortcuts

### §3.6.1 Global Shortcuts (Work From Any Page)

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Cmd+K` / `Ctrl+K` | Open command palette | Primary navigation method for power users |
| `Cmd+B` / `Ctrl+B` | Toggle sidebar | Expand/collapse left sidebar |
| `Cmd+W` / `Ctrl+W` | Open workspace switcher | Quick switch between workspaces |
| `G` then `D` | Go to Dashboard | Two-key shortcut (press G, then D within 1 second) |
| `G` then `N` | Go to Notifications | Two-key shortcut |
| `G` then `S` | Go to Settings | Two-key shortcut |
| `?` | Show keyboard shortcuts help | Opens modal with all shortcuts |

### §3.6.2 Workspace Shortcuts (Work When Inside a Workspace)

| Shortcut | Action | Notes |
|----------|--------|-------|
| `G` then `O` | Go to workspace Overview | |
| `G` then `E` | Go to Documents | "E" for editor |
| `G` then `T` | Go to Tasks | |
| `G` then `M` | Go to Members | |
| `G` then `A` | Go to Activity | |
| `G` then `F` | Go to Files | |
| `C` | Create new item | Opens create menu: Document or Task |
| `C` then `D` | Create new Document | Direct create |
| `C` then `T` | Create new Task | Direct create |

### §3.6.3 Task Board Shortcuts

| Shortcut | Action | Notes |
|----------|--------|-------|
| `←` `→` | Move between columns | When a task card is focused |
| `↑` `↓` | Move between tasks in column | |
| `Enter` | Open task detail | When a task card is focused |
| `E` | Edit task | When a task detail is open |
| `A` | Assign task | Opens assignee picker |
| `L` | Add label | Opens label picker |
| `D` | Set due date | Opens date picker |
| `P` | Set priority | Cycles through priorities |
| `Backspace` / `Delete` | Delete task | With confirmation |

### §3.6.4 Document Editor Shortcuts

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Cmd+S` / `Ctrl+S` | Force save | Triggers immediate save (auto-save is default) |
| `Cmd+Shift+E` | Toggle editor focus mode | Hides sidebar and nav for distraction-free writing |
| `Cmd+Shift+C` | Toggle comment sidebar | Show/hide comment panel |
| `Cmd+Shift+O` | Toggle document outline | Show/hide table of contents |
| `/` | Slash command | Opens block insertion menu |
| `Cmd+Alt+1-6` | Insert heading H1-H6 | |
| `Cmd+Shift+7` | Toggle ordered list | |
| `Cmd+Shift+8` | Toggle bullet list | |
| `Cmd+Shift+9` | Toggle blockquote | |
| `` Cmd+E `` | Toggle inline code | |
| `Cmd+Shift+K` | Insert link | |
| `Cmd+Shift+X` | Toggle strikethrough | |
| Standard formatting | `Cmd+B` bold, `Cmd+I` italic, `Cmd+U` underline | Standard text editing |
