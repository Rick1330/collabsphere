## §3.8 Responsive Design Specifications

### §3.8.1 Breakpoints

| Name | Range | Target Device |
|------|-------|--------------|
| **Mobile** | 0–767px | Phones |
| **Tablet** | 768–1279px | Tablets, small laptops |
| **Desktop** | 1280–1919px | Standard laptops and monitors |
| **Wide** | 1920px+ | Large monitors, ultrawide |

### §3.8.2 Layout Behavior Per Breakpoint

| Component | Mobile (<768px) | Tablet (768–1279px) | Desktop (≥1280px) |
|-----------|----------------|--------------------|--------------------|
| **Top Nav** | Simplified: hamburger + logo + bell + avatar. Search hidden (accessible via Cmd+K). Workspace switcher hidden (accessible via hamburger menu). | Full top nav, search bar slightly narrower | Full top nav with all elements |
| **Left Sidebar** | Hidden. Opens as full-screen slide-over via hamburger. | Collapsed to 60px icons by default. Expands as overlay on click. | Visible at 260px. Collapsible to 60px. |
| **Main Content** | Full width, 16px padding | Full width minus sidebar (if collapsed: full width) | Width minus sidebar, max-width 1200px centered |
| **Document Editor** | Full-screen editor. Toolbar simplified (most-used 6 buttons visible, rest in overflow menu). Comment sidebar hidden (accessible via icon). | Editor with reduced toolbar. Comment sidebar toggleable. | Full editor with toolbar, optional comment sidebar on right (320px), optional outline on left. |
| **Task Board** | Single column view. Swipe horizontally between columns. Or switch to list view (default on mobile). | All columns visible, narrower cards | All columns visible, full cards |
| **Task Detail** | Full-screen page | Slide-over panel from right (480px) | Slide-over panel from right (560px) |
| **Tables / Lists** | Card layout instead of table rows. Horizontal scroll for essential tables. | Responsive table with horizontal scroll if needed | Full table layout |
| **Modals / Dialogs** | Full-screen (bottom sheet pattern on iOS-style devices) | Centered modal, max-width 600px | Centered modal, max-width 640px |
| **Command Palette** | Full-width, top-aligned | Centered, 600px wide | Centered, 640px wide |

### §3.8.3 Touch Interactions (Mobile/Tablet)

| Interaction | Behavior |
|-------------|----------|
| Swipe right from left edge | Open sidebar |
| Swipe left on sidebar | Close sidebar |
| Swipe left/right on task board | Navigate between columns |
| Long press on task card | Open context menu (edit, assign, move, delete) |
| Pull down on list | Refresh data |
| Swipe left on notification | Mark as read / dismiss |
