# §4 — User Flows & Journeys

## §4.1 Flow Catalog (What Must Work End-to-End)

CollabSphere is defined by a set of end-to-end user journeys. Each journey below represents a demo-able, testable scenario and must be covered by E2E tests.

### §4.1.1 Critical Flows (P0 — Launch Blocking)

| Flow ID | Flow Name | Primary Personas | Context |
|--------:|-----------|------------------|---------|
| FL-001 | User onboarding (register → verify email → login) | Student, Developer | Global |
| FL-002 | OAuth onboarding (Google login) | Student, Developer | Global |
| FL-003 | Workspace creation (type + template) | Project Lead, Supervisor, EM | Global → Workspace |
| FL-004 | Workspace invitation (invite → accept → join) | All | Global → Workspace |
| FL-005 | Document creation + real-time collaboration | Student, Developer | Workspace |
| FL-006 | Task lifecycle (create → assign → move across board) | Project Lead, Developer | Workspace |
| FL-007 | Commenting + mentions (docs + tasks) | All | Workspace |
| FL-008 | Notifications (in-app + email) | All | Global + Workspace |
| FL-009 | Search (workspace scoped + global) | All | Global + Workspace |
| FL-010 | Academic submission/review workflow | Student, Supervisor | Academic workspace |

### §4.1.2 Important Flows (P1 — Essential Usability)

| Flow ID | Flow Name | Primary Personas | Context |
