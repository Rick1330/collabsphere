# §8.5 Documents, Folders, Versions, Submissions (CRDT-Compatible)

## §8.5.1 Table: `folders`

**Purpose:** Hierarchical organization container for documents within a workspace.

```sql
CREATE TABLE folders (
  id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id  uuid NOT NULL REFERENCES workspaces(id),

  name         varchar(120) NOT NULL,
  parent_id    uuid REFERENCES folders(id),
  position     numeric(20,10) NOT NULL,           -- fractional ordering

  created_by   uuid NOT NULL REFERENCES users(id),

  created_at   timestamptz NOT NULL DEFAULT now(),
  updated_at   timestamptz NOT NULL DEFAULT now(),
  deleted_at   timestamptz
);

CREATE INDEX idx_folders_workspace_parent_pos
  ON folders(workspace_id, parent_id, position)
  WHERE deleted_at IS NULL;

CREATE INDEX idx_folders_workspace
  ON folders(workspace_id)
  WHERE deleted_at IS NULL;
```

**Rules**
- Prevent cycles (folder cannot be moved into its own descendant) — enforced in application layer.
- v1 deletion rule: cannot delete a non-empty folder (`FOLDER_NOT_EMPTY`).

## §8.5.2 Table: `documents`

**Purpose:** Document metadata + canonical CRDT content state (Yjs) + derived plaintext for search.

```sql
CREATE TABLE documents (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id     uuid NOT NULL REFERENCES workspaces(id),
  folder_id        uuid REFERENCES folders(id),

  title           varchar(200) NOT NULL,
  position        numeric(20,10) NOT NULL,         -- ordering within folder

  status          varchar(30) NOT NULL DEFAULT 'draft',  -- draft|submitted|changes_requested|approved|archived

  is_locked       boolean NOT NULL DEFAULT false,
  locked_by_user_id uuid REFERENCES users(id),
  locked_at       timestamptz,

  -- Canonical content store (CRDT state)
  content_yjs     bytea NOT NULL DEFAULT ''::bytea,

  -- Derived fields for search/diff
  content_plaintext text NOT NULL DEFAULT '',
  search_vector   tsvector,

  created_by      uuid NOT NULL REFERENCES users(id),
  updated_by      uuid REFERENCES users(id),

  created_at      timestamptz NOT NULL DEFAULT now(),
  updated_at      timestamptz NOT NULL DEFAULT now(),
  deleted_at      timestamptz
);

CREATE INDEX idx_documents_workspace_folder_pos
  ON documents(workspace_id, folder_id, position)
  WHERE deleted_at IS NULL;

CREATE INDEX idx_documents_workspace_updated
  ON documents(workspace_id, updated_at DESC)
  WHERE deleted_at IS NULL;

CREATE INDEX idx_documents_status
  ON documents(workspace_id, status)
  WHERE deleted_at IS NULL;

-- Full-text search index
CREATE INDEX idx_documents_search_vector
  ON documents
  USING GIN (search_vector);
```

### Maintaining `search_vector`
In practice you’ll update `search_vector` in app logic when `content_plaintext` or title changes. Optionally use a trigger.

Example trigger (optional):
```sql
CREATE FUNCTION documents_search_vector_update() RETURNS trigger AS $$
begin
  new.search_vector :=
    setweight(to_tsvector('english', coalesce(new.title,'')), 'A') ||
    setweight(to_tsvector('english', coalesce(new.content_plaintext,'')), 'B');
  return new;
end
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_documents_search_vector
BEFORE INSERT OR UPDATE OF title, content_plaintext
ON documents
FOR EACH ROW EXECUTE FUNCTION documents_search_vector_update();
```

**Rules**
- `content_yjs` is the canonical representation.
- `content_plaintext` is derived and may lag slightly (acceptable).
- Access to document content occurs via collaboration server, not REST.
- `folder_id` must belong to same workspace (enforced by service).

## §8.5.3 Table: `document_versions`

**Purpose:** Immutable snapshots of document CRDT state for history + restore + academic submissions.

```sql
CREATE TABLE document_versions (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id   uuid NOT NULL REFERENCES workspaces(id),
  document_id    uuid NOT NULL REFERENCES documents(id),

  version_number int NOT NULL,
  reason        varchar(30) NOT NULL,             -- manual|auto|submitted|approved|before_restore

  yjs_state     bytea NOT NULL,
  plaintext     text,

  created_by    uuid REFERENCES users(id),        -- null means system
  created_at    timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX uq_doc_versions_number
  ON document_versions(document_id, version_number);

CREATE INDEX idx_doc_versions_doc_created
  ON document_versions(document_id, created_at DESC);

CREATE INDEX idx_doc_versions_workspace_created
  ON document_versions(workspace_id, created_at DESC);
```

**Rules**
- Versions are immutable. No update/delete endpoints in v1.
- Restore:
  - creates `before_restore` version first
  - then replaces document `content_yjs`

## §8.5.4 Table: `document_submissions` (Academic workflow)

**Purpose:** Records each submission cycle and supervisor decision.

```sql
CREATE TABLE document_submissions (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id     uuid NOT NULL REFERENCES workspaces(id),
  document_id      uuid NOT NULL REFERENCES documents(id),

  submitted_by     uuid NOT NULL REFERENCES users(id),
  submitted_at     timestamptz NOT NULL DEFAULT now(),

  snapshot_version_id uuid REFERENCES document_versions(id),  -- points to version saved on submit

  decision         varchar(30),              -- approved|changes_requested|null
  decided_by       uuid REFERENCES users(id),
  decided_at       timestamptz,
  decision_note    text,

  created_at       timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_doc_submissions_document
  ON document_submissions(document_id, submitted_at DESC);

CREATE INDEX idx_doc_submissions_workspace
  ON document_submissions(workspace_id, submitted_at DESC);
```

**Rules**
- On submit:
  - create a document version with reason `submitted`
  - create a submission pointing to that version
  - set document.status = `submitted`
- On review:
  - update latest submission decision fields
  - set document.status accordingly

## §8.5.5 Document Locking Data Integrity

Rules:
- When `documents.is_locked = true`, must have `locked_by_user_id` and `locked_at`.
- When unlocked, set `is_locked=false`, `locked_by_user_id=null`, `locked_at=null`.

This is enforced in service layer.

---

## §8.5.6 Deletion & Retention (Documents)

Soft delete:
- set `documents.deleted_at = now()`
- keep versions and submissions (optional) for retention period

Retention defaults:
- documents: 30 days
- versions: keep as long as document exists, purge with document purge
- submissions: keep as long as document exists (or longer for academic compliance; configurable)
