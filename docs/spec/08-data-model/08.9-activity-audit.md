# §8.9 Activity Events & Audit Log (Persistence)

## §8.9.1 Table: `activity_events`

**Purpose:** Workspace-scoped, user-facing activity feed entries.

```sql
CREATE TABLE activity_events (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id   uuid NOT NULL REFERENCES workspaces(id),

  actor_id      uuid REFERENCES users(id),
  actor_name_snapshot varchar(200) NOT NULL,
  actor_avatar_snapshot varchar(500),

  event_key     varchar(80) NOT NULL,              -- e.g., "task.assigned"
  summary       varchar(255) NOT NULL,

  resource_type varchar(40),
  resource_id   uuid,
  resource_title_snapshot varchar(255),

  metadata      jsonb NOT NULL DEFAULT '{}'::jsonb,

  created_at    timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_activity_events_workspace_created
  ON activity_events(workspace_id, created_at DESC);

CREATE INDEX idx_activity_events_workspace_event
  ON activity_events(workspace_id, event_key, created_at DESC);

CREATE INDEX idx_activity_events_workspace_actor
  ON activity_events(workspace_id, actor_id, created_at DESC);
```

**Notes**
- Activity events are append-only in v1 (no edits/deletes).
- Actor snapshot fields help display even if user later changes name/avatar or is deleted.

## §8.9.2 Table: `audit_log`

**Purpose:** Admin-only, security-sensitive append-only log.

```sql
CREATE TABLE audit_log (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  request_id       varchar(64),

  severity        varchar(10) NOT NULL,            -- info|warn|error
  action_key      varchar(120) NOT NULL,           -- e.g., "security.login_failed"

  actor_id        uuid REFERENCES users(id),
  actor_email     citext,
  actor_global_role varchar(20),

  workspace_id    uuid REFERENCES workspaces(id),
  target_type     varchar(40),
  target_id       uuid,

  ip_address      varchar(64),
  user_agent      text,

  metadata        jsonb NOT NULL DEFAULT '{}'::jsonb,

  created_at      timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_audit_log_created
  ON audit_log(created_at DESC);

CREATE INDEX idx_audit_log_action_created
  ON audit_log(action_key, created_at DESC);

CREATE INDEX idx_audit_log_actor_email
  ON audit_log(actor_email, created_at DESC);

CREATE INDEX idx_audit_log_workspace
  ON audit_log(workspace_id, created_at DESC);
```

**Rules**
- No update/delete endpoints.
- Retention default: 365 days (configurable).
- Sensitive payloads:
  - never store passwords, tokens, raw OAuth codes
  - store reason codes only
