# §8.10 Templates (Persistence)

## §8.10.1 Table: `templates`

**Purpose:** Stores system templates (v1) and enables future expansion to workspace/org/public templates.

```sql
CREATE TABLE templates (
  id             varchar(120) PRIMARY KEY,          -- stable string id (e.g., tpl_doc_academic_srs_v1)

  kind           varchar(20) NOT NULL,              -- workspace | document
  category       varchar(20) NOT NULL,              -- professional | academic | general
  scope          varchar(20) NOT NULL DEFAULT 'system', -- system|workspace|organization|public

  name           varchar(120) NOT NULL,
  description    varchar(280),

  version        int NOT NULL DEFAULT 1,
  schema_version int NOT NULL DEFAULT 1,

  content_format varchar(20),                       -- markdown|json (document templates)
  content        jsonb NOT NULL,                    -- template body

  is_enabled     boolean NOT NULL DEFAULT true,

  created_by_user_id uuid REFERENCES users(id),     -- null for system templates
  workspace_id   uuid REFERENCES workspaces(id),    -- null for system templates

  created_at     timestamptz NOT NULL DEFAULT now(),
  updated_at     timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_templates_kind_category_scope
  ON templates(kind, category, scope);

CREATE INDEX idx_templates_enabled
  ON templates(is_enabled)
  WHERE is_enabled = true;
```

**Rules**
- v1: only `scope='system'` templates are used.
- v1.1: allow `scope='workspace'` with `workspace_id` populated.

## §8.10.2 Template Content Storage Strategy

### Workspace Templates
- `content` stores the workspace template JSON:
  - folder structure
  - documents to create (by document template id)
  - task columns
  - settings defaults

### Document Templates
- `content` stores:
  - markdown content (stored inside JSONB as `{ "markdown": "..." }`)
  - OR tiptap JSON (stored as `{ "doc": { ... } }`)

**Recommendation (v1):**
- store markdown, convert to tiptap/yjs state on document creation.

Example `content` for document template:
```json
{
  "markdown": "# SRS\n\n## 1. Introduction\n\n..."
}
```
