## §16.6 Release Readiness Criteria (v1 “Go/No-Go”)

### Functional Readiness
- [ ] All critical flows FL-001 through FL-010 pass in staging
- [ ] No P0 bugs open
- [ ] Role enforcement verified for:
  - Viewer cannot create/edit tasks/docs
  - Non-member cannot access workspace resources

### Performance Readiness
- [ ] Dashboard and workspace pages meet NFR targets (see §6)
- [ ] Search latency acceptable (<800ms typical)
- [ ] Collaboration sync acceptable (<500ms typical)

### Security Readiness
- [ ] No cross-workspace data leakage found in tests
- [ ] No critical OWASP vulnerabilities (basic scan)
- [ ] Audit logging captures auth failures and role changes

### Operational Readiness
- [ ] CI green on main
- [ ] Database migrations documented and repeatable
- [ ] Backup strategy configured for staging/prod
- [ ] Error responses include requestId everywhere
