## §16.5 Critical Path (What Blocks What)

The main critical path for v1 is:

1. Auth + session security  
2. Workspace + membership + RBAC  
3. Templates (workspace initializer)  
4. Document hierarchy + editor scaffolding  
5. **Realtime collaboration (Tiptap + Yjs + Hocuspocus)**  
6. Comments/mentions  
7. Tasks + assignment + status workflow  
8. Notifications + activity + search  
9. Academic submission workflow  
10. Admin + hardening  

If realtime collaboration slips, v1 value drops significantly; it must be addressed early (Phase 6).
