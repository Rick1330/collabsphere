## §16.3 Release Definitions

### §16.3.1 v1.0 — “Foundation Product”
**Goal:** A team can use CollabSphere daily for docs + tasks + collaboration.

**Must include:**
- Auth (local + Google OAuth)
- Workspaces + membership + roles
- Templates (built-in)
- Documents (hierarchy + realtime editing + locking + versioning basics)
- Tasks (Kanban + list view basics)
- Comments + mentions
- Notifications (in-app + email basic)
- Activity feed
- Search (docs + tasks)
- Admin console basics
- Observability baseline + CI

### §16.3.2 v1.1 — “Polish + Adoption”
**Goal:** Improve usability + operability; add high-impact enhancements.

Includes (examples):
- File uploads + attachments
- Better mobile experience
- Notification digest
- Custom templates (workspace scope)
- Better editor features (slash commands, outline)
- Analytics improvements

### §16.3.3 v2.0+ — “Platform”
**Goal:** Become integration-ready platform with public APIs and extensibility.

Includes:
- Webhooks
- GitHub/Slack integrations
- Import utilities (Trello/Notion)
- SSO/SAML (enterprise)
- Plugin ecosystem (long-term)
