## §16.7 Contributor Onboarding Readiness (Open Source Readiness)

Before inviting external contributors:
- [ ] CONTRIBUTING.md exists (setup, branching, PR rules)
- [ ] Code style and linting enforced in CI
- [ ] Module boundaries documented (README per module)
- [ ] “Good first issue” labels exist
- [ ] Minimal architecture diagram included
