## §10.6 Realtime Authorization Rules (Critical)

### §10.6.1 Room Join Authorization
Server must validate join requests:
- `user:<userId>` can only be joined by that user
- `workspace:<workspaceId>` requires active workspace membership
- `task:<taskId>` requires access to that task’s workspace and task
- `doc-meta:<documentId>` requires access to that document’s workspace and document

### §10.6.2 Payload Privacy
- Never include cross-workspace metadata in events
- Notification payload includes only recipient-safe info
- Task updates emitted to workspace room only
