## §10.5 Socket.IO Event Catalog (Authoritative)

### §10.5.1 Connection Events

#### `server:connected`
Direction: server → client  
Payload:
```json
{ "userId": "uuid", "connectedAt": "2025-07-17T12:00:00Z" }
```

#### `client:join`
Direction: client → server  
Payload:
```json
{ "room": "workspace:ws-uuid" }
```

Errors:
- `client:join_denied` if user not allowed.

---

### §10.5.2 Notification Events

#### `notification:new`
Room: `user:<userId>`  
Payload:
```json
{
  "id": "notif-uuid",
  "type": "task.assigned",
  "workspaceId": "ws-uuid",
  "title": "Task assigned to you",
  "body": "Implement login page",
  "url": "/w/ws-uuid/tasks/task-uuid",
  "isRead": false,
  "createdAt": "2025-07-17T12:00:00Z"
}
```

#### `notification:count`
Room: `user:<userId>`  
Payload:
```json
{ "unreadCount": 12 }
```

#### `notification:read` (optional v1)
Direction: client → server  
Payload:
```json
{ "notificationId": "notif-uuid" }
```

---

### §10.5.3 Task Events

All task events are emitted to:
- `workspace:<workspaceId>`
and optionally:
- `task:<taskId>` when applicable.

#### `task:created`
Payload:
```json
{
  "task": {
    "id": "task-uuid",
    "title": "Implement login page",
    "status": "todo",
    "priority": "high",
    "assigneeId": "user-uuid",
    "dueDate": "2025-08-01",
    "position": 5.0
  }
}
```

#### `task:updated`
Payload:
```json
{
  "taskId": "task-uuid",
  "changes": {
    "title": "New title",
    "priority": "urgent"
  },
  "updatedAt": "2025-07-17T12:10:00Z"
}
```

#### `task:moved`
Payload:
```json
{
  "taskId": "task-uuid",
  "fromStatus": "todo",
  "toStatus": "in_progress",
  "position": 2.5
}
```

#### `task:assigned`
Payload:
```json
{
  "taskId": "task-uuid",
  "fromAssigneeId": null,
  "toAssigneeId": "user-uuid"
}
```

#### `task:deleted`
Payload:
```json
{ "taskId": "task-uuid" }
```

---

### §10.5.4 Activity Events

Emitted to:
- `workspace:<workspaceId>`

#### `activity:new`
Payload:
```json
{
  "id": "evt-uuid",
  "eventKey": "task.assigned",
  "summary": "Jane assigned “Implement login” to Bob",
  "actor": { "id": "u1", "fullName": "Jane" },
  "resource": { "type": "task", "id": "t1", "title": "Implement login" },
  "createdAt": "2025-07-17T12:00:00Z"
}
```

---

### §10.5.5 Workspace Member Events (Optional P1)

Emitted to:
- `workspace:<workspaceId>`

#### `workspace:member_joined`
Payload:
```json
{ "userId": "uuid", "fullName": "Alice", "role": "MEMBER" }
```

#### `workspace:member_removed`
Payload:
```json
{ "userId": "uuid" }
```

#### `workspace:role_changed`
Payload:
```json
{ "userId": "uuid", "fromRole": "MEMBER", "toRole": "MANAGER" }
```

---

### §10.5.6 Document Metadata Events (Lock/Status)

Emitted to:
- `workspace:<workspaceId>`
and optionally `doc-meta:<documentId>`

#### `document:locked`
Payload:
```json
{
  "documentId": "doc-uuid",
  "lockedBy": { "id": "u1", "fullName": "Jane" },
  "lockedAt": "2025-07-17T12:00:00Z"
}
```

#### `document:unlocked`
Payload:
```json
{ "documentId": "doc-uuid" }
```

#### `document:status_changed`
Payload:
```json
{ "documentId": "doc-uuid", "from": "draft", "to": "submitted" }
```
