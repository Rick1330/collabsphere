## §10.3 Realtime System B — Application Events (Socket.IO)

### §10.3.1 Responsibilities
- Push in-app notifications in real time
- Broadcast workspace activity events
- Broadcast task changes (created/updated/moved)
- Broadcast comment thread updates (create/edit/delete/resolve)
- Provide lightweight workspace presence (optional P1)
- Enable optimistic UI reconciliation (client updates on server events)

### §10.3.2 WebSocket Endpoint
- `wss://api.collabsphere.io/socket`

### §10.3.3 Namespaces
- v1: single default namespace `/`

### §10.3.4 Authentication & Connection Lifecycle

#### Connect
Client connects with JWT:
- `auth: { token: "<JWT>" }`

Server:
- validates token
- attaches `userId` and `globalRole` to socket context

#### Disconnect
Server removes socket from rooms and presence maps.

#### Reconnect
Socket.IO auto-reconnects.
Client must rejoin rooms on reconnect.
