## §10.7 Scaling Strategy (v1 vs v2)

### §10.7.1 v1 (Single instance acceptable)
- Socket.IO runs on same node instance as API or a separate service
- No adapter required if single node
- Hocuspocus can run single instance

### §10.7.2 v1.1/v2 (Horizontal scaling)
- Socket.IO uses Redis adapter:
  - ensures events broadcast across instances
- Hocuspocus uses Redis for awareness/pubsub:
  - multiple collaboration nodes can serve same document rooms
