# §10 — Realtime Systems (Socket.IO + Hocuspocus/Yjs)

## §10.1 Overview

CollabSphere uses two realtime systems:

1) **Document Collaboration Realtime** — handled by **Hocuspocus** (Yjs CRDT sync + awareness)  
2) **Application Realtime Events** — handled by **Socket.IO** (notifications, tasks, activity, presence)

This separation keeps the CRDT collaboration pipeline isolated and stable, while allowing the rest of the app to evolve independently.
