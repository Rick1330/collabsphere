## §17.3 Technical Terms

| Term | Definition | Notes |
|------|------------|------|
| **CRDT** | Conflict-free Replicated Data Type — data structure that merges concurrent edits deterministically. | Used for documents |
| **Yjs** | A CRDT library used for collaborative text editing. | Canonical doc state |
| **Hocuspocus** | WebSocket server for Tiptap/Yjs collaboration with auth and persistence hooks. | Handles doc realtime |
| **Tiptap** | Rich-text editor framework built on ProseMirror. | UI editor |
| **ProseMirror** | Underlying document editing engine. | Tiptap is based on it |
| **Awareness** | Yjs concept for presence/cursor state (not persisted). | “Who’s editing” |
| **Socket.IO** | WebSocket abstraction for app realtime events (notifications/tasks/activity). | Separate from Hocuspocus |
| **JWT** | JSON Web Token — signed token for access authorization. | 15 minutes TTL |
| **Refresh Token** | Long-lived token to obtain new JWT access tokens. | Stored as httpOnly cookie |
| **RBAC** | Role-Based Access Control — permissions based on roles. | Workspace roles |
| **IDOR** | Insecure Direct Object Reference — accessing resources by guessing IDs. | Prevent via workspace scoping |
| **CORS** | Cross-Origin Resource Sharing — browser security policy for API access. | Restrict origins |
| **CSRF** | Cross-Site Request Forgery — attacker triggers requests via user cookies. | Mitigate via SameSite + tokens |
| **XSS** | Cross-Site Scripting — attacker injects scripts into content. | Mitigate via sanitization |
| **FTS** | Full-Text Search (PostgreSQL). | Search documents/tasks |
| **GIN Index** | PostgreSQL index type used for full-text search and arrays. | search_vector, labels |
| **BullMQ** | Redis-backed job queue for background work. | email/export/cleanup |
| **Idempotency Key** | A unique key that makes repeated POST requests safe. | `X-Idempotency-Key` |
| **Request ID** | Unique identifier for a request used for correlation. | `X-Request-Id` |
| **RUM** | Real User Monitoring — measuring real user performance. | v1.1+ |
| **LCP** | Largest Contentful Paint — performance metric for perceived load speed. | Target <2.5s |
| **p95 / p99** | Percentile latency measurements. | API performance targets |
| **Modular Monolith** | Single deployable app with clean module boundaries. | NestJS modules |
| **Monorepo** | Single repo containing multiple apps/packages. | web/api/collab/worker |
