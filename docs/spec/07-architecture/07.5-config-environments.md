## §7.5 Configuration & Environments

### §7.5.1 Environments
- `local`
- `staging`
- `production`

### §7.5.2 Config Rules
- All config comes from environment variables (`.env`)
- Secrets are never committed
- Typed config loader validates required env vars at startup

### §7.5.3 Required Environment Variables (v1 minimum)

**API**
- `DATABASE_URL`
- `REDIS_URL`
- `JWT_ACCESS_SECRET`
- `JWT_ACCESS_TTL_MINUTES=15`
- `REFRESH_TOKEN_TTL_DAYS=7`
- `CORS_ORIGINS=https://...`
- `EMAIL_PROVIDER_API_KEY`
- `BASE_URL=https://collabsphere.io`

**Collab (Hocuspocus)**
- `COLLAB_DATABASE_URL`
- `COLLAB_REDIS_URL` (optional for scaling)
- `COLLAB_JWT_SECRET` (shared with API or dedicated)
- `COLLAB_WS_URL=wss://api.../collaboration`

**Files (v1.1+)**
- `S3_ENDPOINT` (optional for MinIO)
- `S3_BUCKET`
- `S3_ACCESS_KEY_ID`
- `S3_SECRET_ACCESS_KEY`
- `S3_REGION`
