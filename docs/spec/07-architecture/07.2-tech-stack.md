## §7.2 Authoritative Technology Stack (v1)

### §7.2.1 Core Stack Summary

| Layer | Technology | Version (Target) | Purpose |
|------|------------|------------------|---------|
| Language | TypeScript | 5.5+ | Type safety across backend + frontend |
| Monorepo | Turborepo | latest stable | Build orchestration, caching |
| Package manager | pnpm | 9.x | Fast installs, workspace support |
| Frontend | Next.js App Router | — | Current product frontend foundation in `apps/web`, including App Router layouts for public, global, workspace, and admin contexts |
| UI | App Router global CSS + React components | — | Minimal accessible shell and route-foundation styling landed in the platform transition; richer shared UI remains downstream work |
| Client state | Zustand | 4.x | UI/session state |
| Server state | TanStack Query | 5.x | API caching, mutations, optimistic UI |
| Forms/validation | React Hook Form + Zod | latest stable | Typed validation and UX |
| Editor | Tiptap | 2.x | Rich-text editor |
| CRDT | Yjs | latest stable | Real-time shared document state |
| Collaboration server | Hocuspocus | latest stable | WebSocket sync, awareness, persistence hooks |
| Backend | NestJS | 10.x | Modular API, guards, DI |
| ORM | Prisma | 5.x | DB schema, migrations, typed queries |
| Database | PostgreSQL | 16 | Primary persistence + FTS |
| Cache / shared infra | Redis | 7.x | rate limiting, queues, adapters |
| Jobs/queue | BullMQ | 5.x | email/export/cleanup workers |
| Realtime (non-editor) | Socket.IO | 4.x | notifications/activity/task updates |
| File storage | S3-compatible | AWS S3 / MinIO | uploads/downloads with presigned URLs |
| Email | Resend (or SendGrid) | — | transactional email + digest |
| Containerization | Docker + Compose | latest stable | local dev + deployment parity |
| CI | GitHub Actions | — | tests, lint, build, deploy (later) |

> Notes:
> - `#1508` replaced the former static placeholder with the current Next.js App Router foundation in `apps/web`.
> - Feature stories still need to layer in auth, navigation behavior, theme controls, and product-complete UI on top of that foundation.
> - Hocuspocus handles **document realtime collaboration**. Socket.IO handles **app realtime events** (tasks, notifications, activity).
> - PostgreSQL Full-Text Search (FTS) is used for v1 search; Elasticsearch is v2+.
