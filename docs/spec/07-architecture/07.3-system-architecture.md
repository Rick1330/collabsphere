## §7.3 System Architecture (High-Level)

### §7.3.1 Architectural Pattern: Modular Monolith + Realtime Sidecars

CollabSphere uses a **modular monolith** backend (NestJS) with two realtime servers:

1) **API Server (NestJS)** — REST APIs, auth, RBAC, business logic  
2) **Collaboration Server (Hocuspocus)** — Yjs document sync + awareness  
3) **App Realtime Server (Socket.IO)** — notifications/activity/tasks realtime updates  

These can run:
- in the same Node process (not recommended), or
- as **separate Node services** deployed together (recommended).

**v1 recommendation:** separate services, same repository, deployed together.
