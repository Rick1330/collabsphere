## §11.2 Security Principles (Authoritative)

1. **Default deny**  
   If access is not explicitly allowed by RBAC, it is forbidden.

2. **Workspace isolation is absolute**  
   Workspace data must never be accessible outside its workspace scope.

3. **Defense-in-depth**  
   Enforce authorization at multiple layers:
   - route guard
   - service-level validation
   - DB-level scoping
   - tests that verify isolation

4. **Minimize sensitive data exposure**  
   - never return secrets or internal traces
   - avoid logging PII and user content where possible

5. **Least privilege**  
   - Platform Admin powers are limited to admin routes
   - users do not gain workspace membership implicitly
