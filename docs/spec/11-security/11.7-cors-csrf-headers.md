## §11.7 CORS, CSRF, Secure Headers

### §11.7.1 CORS
- Allow only known frontend origins in production
- No wildcard `*`
- Allow credentials if using cookies for refresh token

### §11.7.2 CSRF
- Refresh token in cookies introduces CSRF risk:
  - Use SameSite=Lax minimum
  - Refresh endpoint is POST only
  - Consider CSRF token in v1.1 if needed

### §11.7.3 Secure Headers (recommended)
- `Strict-Transport-Security`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY` (or CSP frame-ancestors)
- `Content-Security-Policy` (basic)
- `Referrer-Policy: strict-origin-when-cross-origin`
