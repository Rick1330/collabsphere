## §11.8 Realtime Security

### §11.8.1 Socket.IO
- Must authenticate with JWT
- Must authorize room joins (workspace membership required)
- Prevent joining `user:<id>` room for another user
- Apply rate limit on event emission from clients

### §11.8.2 Hocuspocus collaboration server
- Authenticate JWT on connect
- Authorize document access (workspace membership + doc state)
- Reject writes if:
  - user lacks edit permission
  - document locked/submitted/approved for that role
