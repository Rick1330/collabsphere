## §11.5 Input Validation & Output Sanitization

### §11.5.1 Validation
- All API inputs validated with DTO schemas (Zod/class-validator)
- Reject unknown fields (recommended) to reduce attack surface

### §11.5.2 Content Sanitization
- For editor and comments:
  - store structured JSON, not raw HTML
  - sanitize pasted HTML client-side
  - sanitize on server as defense-in-depth
- Prohibit script tags, event handlers, unsafe URLs

### §11.5.3 XSS Protection
- Use React escaping by default
- Avoid dangerouslySetInnerHTML except for trusted rendering pipelines
- For Markdown previews, use strict sanitization library
