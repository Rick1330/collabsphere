## §11.4 Authorization (RBAC) & Workspace Isolation

### §11.4.1 RBAC Enforcement
- Global role checks for admin routes
- Workspace role checks for workspace routes
- Role hierarchy per §2

### §11.4.2 Workspace Isolation Rules (Hard Requirements)
- Every workspace-owned resource query must include `workspace_id`
- Resource IDs alone must not grant access (prevent IDOR)
- Services must validate:
  - resource belongs to workspace
  - user is a member of workspace

### §11.4.3 Cross-workspace data leak prevention
- Integration tests must include “A cannot access B” for each resource:
  - tasks
  - documents
  - comments
  - notifications
  - files
  - exports
