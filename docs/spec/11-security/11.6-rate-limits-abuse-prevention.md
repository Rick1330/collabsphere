## §11.6 Rate Limiting & Abuse Prevention

### §11.6.1 Rate limiting
- Auth endpoints: strict
- Write endpoints: moderate
- Read endpoints: higher

Return `429 RATE_LIMITED` with `Retry-After`.

### §11.6.2 Invitation abuse prevention
- Max invites/day per workspace (configurable)
- Rate limit invite creation per user

### §11.6.3 Search abuse
- Rate limit search endpoint (e.g., 60/min)
- Cap query length
