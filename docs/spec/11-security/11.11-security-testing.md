## §11.11 Security Testing Requirements

### Automated
- OWASP ZAP baseline scan (P2)
- dependency scanning (npm audit, Snyk optional)
- RBAC integration tests for every resource type

### Manual
- Attempt IDOR by swapping resource IDs across workspaces
- Attempt XSS via comment content
- Attempt privilege escalation via role change endpoints
