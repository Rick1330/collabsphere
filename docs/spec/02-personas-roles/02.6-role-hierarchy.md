## §2.6 Role Hierarchy Visualization

```
Platform Level:
  ADMIN ─────────────────────────────────────────────
    │  Can manage all users and view all workspaces
    │  (but NOT automatically a member of workspaces)
    │
  USER ──────────────────────────────────────────────
    │  Can create workspaces, join workspaces,
    │  manage own profile

Workspace Level (per workspace):

  OWNER (Level 5) ───────────────────────────────────
    │  Full control. Delete workspace. Transfer ownership.
    │  All permissions of Admin+
    │
  ADMIN (Level 4) ───────────────────────────────────
    │  Manage members. Change settings. Manage templates.
    │  All permissions of Manager+
    │
  MANAGER (Level 3) ─────────────────────────────────
    │  Assign tasks. Review submissions. View analytics.
    │  Manage content organization.
    │  All permissions of Member+
    │
  MEMBER (Level 2) ──────────────────────────────────
    │  Create/edit documents. Create/work on tasks.
    │  Post comments. The standard contributor.
    │  All permissions of Viewer+
    │
  VIEWER (Level 1) ──────────────────────────────────
       View content. Post comments on documents.
       Read-only access to all workspace content.
```
