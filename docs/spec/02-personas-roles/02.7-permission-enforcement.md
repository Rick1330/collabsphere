## §2.7 Permission Enforcement Architecture

Permissions are enforced at three layers. All three must pass for an action to succeed.

### Layer 1: Authentication (Global)

Every API request (except public routes) must include a valid JWT access token. Requests without a token or with an expired token receive `401 Unauthorized`.

**Enforced by:** `JwtAuthGuard` applied globally to all protected routes.

### Layer 2: Platform Role Check (Global)

Admin-only routes (user management, system analytics, audit log) check that the user's global role is `ADMIN`. Non-admin users receive `403 Forbidden`.

**Enforced by:** `@Roles('ADMIN')` decorator + `GlobalRolesGuard`.

### Layer 3: Workspace Role Check (Per-Request)

All workspace-scoped routes:
1. Extract `workspaceId` from the URL path
2. Query `workspace_members` to find the user's role in that workspace
3. Compare the user's role level against the minimum role required for the action
4. If the user is not a member of the workspace, return `403 Forbidden`
5. If the user's role level is too low, return `403 Forbidden`

**Enforced by:** `WorkspaceMemberGuard` + `@WorkspaceRoles('MANAGER')` decorator.

```typescript
// Example: Only Manager+ can assign tasks to others
@Patch(':taskId/assign')
@UseGuards(JwtAuthGuard, WorkspaceMemberGuard)
@WorkspaceRoles('MANAGER')  // Minimum role: Manager (Level 3)
async assignTask(
  @Param('taskId') taskId: string,
  @Body() dto: AssignTaskDto,
  @CurrentUser() user: User,
  @CurrentWorkspaceMember() member: WorkspaceMember,
) {
  return this.taskService.assign(taskId, dto, member);
}
```

### RBAC Check Algorithm

```
FUNCTION CheckWorkspaceAccess(userId, workspaceId, requiredRole):

  // Step 1: Find membership
  membership = DB.query(
    "SELECT role FROM workspace_members 
     WHERE user_id = $1 AND workspace_id = $2 AND is_active = true",
    [userId, workspaceId]
  )

  // Step 2: Not a member
  IF membership IS NULL THEN
    RETURN { allowed: false, reason: "NOT_WORKSPACE_MEMBER" }
  END IF

  // Step 3: Compare role levels
  userLevel = ROLE_LEVELS[membership.role]     // e.g., MEMBER = 2
  requiredLevel = ROLE_LEVELS[requiredRole]    // e.g., MANAGER = 3

  IF userLevel >= requiredLevel THEN
    RETURN { allowed: true, role: membership.role }
  ELSE
    RETURN { allowed: false, reason: "INSUFFICIENT_ROLE" }
  END IF

END FUNCTION

// Role level mapping
ROLE_LEVELS = {
  VIEWER: 1,
  MEMBER: 2,
  MANAGER: 3,
  ADMIN: 4,
  OWNER: 5
}
```
