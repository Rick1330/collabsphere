## §2.5 Multi-Role Examples

### Example 1: Academic Context

```
University CS Department — 3 workspaces

Workspace: "Group Alpha — Senior Project"
  Dr. Sarah (Supervisor)    → Owner
  TA Michael               → Admin
  Alice (student lead)     → Manager
  Bob (student)            → Member
  Carol (student)          → Member

Workspace: "Group Beta — Senior Project"  
  Dr. Sarah (Supervisor)    → Owner    ← Same person, same role, different workspace
  TA Michael               → Admin
  Dave (student lead)      → Manager
  Eve (student)            → Member

Workspace: "Study Group — Algorithms"
  Alice                    → Owner    ← Alice is Owner here but Member in Group Alpha
  Bob                      → Member
  Eve                      → Member
```

### Example 2: Professional Context

```
Startup "Acme Inc" — 2 workspaces

Workspace: "Product v2.0"
  CTO Jane                 → Owner
  EM Marcus                → Admin
  Tech Lead Priya          → Manager
  Dev Alex                 → Member
  Dev Jordan               → Member
  Designer Sam             → Member
  PM Casey                 → Manager  ← Two managers (tech lead + PM)
  CEO Dana                 → Viewer   ← CEO just wants visibility

Workspace: "Hiring Pipeline"
  EM Marcus                → Owner    ← Marcus is Owner here but Admin in Product
  HR Kim                   → Admin
  CTO Jane                 → Manager  ← Jane is Manager here but Owner in Product
  Interviewer Alex         → Member
```

### Example 3: Cross-Context

```
Alice is a CS student AND a freelance developer

Workspace: "Senior Project" (Academic type)
  Alice                    → Member (Student role label)

Workspace: "Client Website Redesign" (Professional type)
  Alice                    → Owner
  Client Bob               → Viewer (Stakeholder role label)
```
