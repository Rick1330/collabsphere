## §18.2 Consolidated Realtime Event Catalog (Socket.IO)

Rooms:
- `user:<userId>`
- `workspace:<workspaceId>`
- optional: `task:<taskId>`, `document:<documentId>`, `doc-meta:<documentId>`

| Event | Room | Payload Summary |
|-------|------|-----------------|
| `notification:new` | user | notification summary |
| `notification:count` | user | unreadCount |
| `task:created` | workspace | task summary |
| `task:updated` | workspace | taskId + changes |
| `task:moved` | workspace | from/to status + position |
| `task:assigned` | workspace | from/to assignee |
| `task:deleted` | workspace | taskId |
| `comment:thread_created` | workspace/document/task | threadId + target |
| `comment:created` | workspace/document/task | threadId + commentId + target |
| `comment:updated` | workspace/document/task | threadId + commentId + target |
| `comment:deleted` | workspace/document/task | threadId + commentId + target |
| `comment:thread_resolved` | workspace/document/task | threadId + target |
| `comment:thread_reopened` | workspace/document/task | threadId + target |
| `activity:new` | workspace | activity event summary |
| `workspace:member_joined` | workspace | user summary |
| `workspace:member_removed` | workspace | userId |
| `workspace:role_changed` | workspace | role delta |
| `document:locked` | workspace/doc-meta | documentId + locker |
| `document:unlocked` | workspace/doc-meta | documentId |
| `document:status_changed` | workspace/doc-meta | from/to |
