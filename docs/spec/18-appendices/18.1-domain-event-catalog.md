# §18 — Appendices

## §18.1 Consolidated Domain Event Catalog (Internal Event Bus)

Domain events are emitted by core services to decouple side effects (notifications, activity feed, audit logs, realtime pushes, integrations).

### §18.1.1 Event Envelope (Canonical)

```json
{
  "eventId": "evt_01J2...",
  "name": "task.assigned",
  "occurredAt": "2025-07-17T12:00:00Z",
  "actor": {
    "userId": "uuid",
    "workspaceId": "uuid-or-null"
  },
  "data": { }
}
```

Rules:
- `eventId` must be unique and stable (use ULID/UUID)
- `occurredAt` UTC ISO
- `actor.workspaceId` present for workspace events
- `data` schema depends on event name
