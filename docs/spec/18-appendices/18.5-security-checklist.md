## §18.5 Security Checklist (v1)

- [ ] Passwords hashed (bcrypt/argon2)
- [ ] Refresh tokens stored hashed and rotated
- [ ] OAuth state enforced
- [ ] RBAC enforced on every workspace-scoped endpoint
- [ ] Workspace isolation tests exist for every resource type
- [ ] Input validation on all endpoints
- [ ] XSS sanitization for comments/editor content
- [ ] Rate limiting enabled
- [ ] CORS allowlist configured
- [ ] No stack traces in API responses
- [ ] Audit log records sensitive actions
- [ ] Secure headers configured
- [ ] File uploads restricted by MIME/size (v1.1)
