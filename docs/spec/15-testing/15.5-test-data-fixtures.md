## §15.5 Test Data & Fixtures

- Use factory helpers to create:
  - users (local + oauth)
  - workspaces (professional/academic)
  - memberships with roles
  - documents (with seeded yjs state)
  - tasks with different statuses
- Avoid shared global test state (tests must be isolated)
- Database reset between integration test suites:
  - transaction rollback per test OR truncate tables per suite
