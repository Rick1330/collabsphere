## §15.3 Tools (v1)

### Frontend
- Unit/component: Vitest + Testing Library
- E2E: Playwright

### Backend
- Unit: Vitest or Jest (choose one; Vitest recommended for speed)
- Integration: supertest + test DB (Postgres via Docker)
- Realtime tests:
  - minimal integration tests for socket events
  - (collab) local Hocuspocus integration tests where feasible
