## §15.2 Testing Pyramid (v1 Targets)

| Test Type | Target % of Test Suite | Purpose |
|----------|-------------------------|---------|
| Unit tests | 60–70% | Validate pure logic, validators, state machines |
| Integration tests | 20–30% | Validate DB, guards, module wiring, event listeners |
| E2E tests (Playwright) | 10–15% | Validate critical user flows end-to-end |
