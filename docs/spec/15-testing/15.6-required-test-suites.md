## §15.6 Required Test Suites (by Module)

### Auth
- register/verify/login/refresh/logout
- token rotation correctness
- rate limiting (smoke)
- deactivated user blocked

### Workspaces/Memberships
- create workspace sets owner membership
- invite/accept join
- role changes enforced
- archived workspace blocks writes

### Documents
- create doc from template seeds state
- lock/unlock enforce permissions
- submission/review transitions (academic mode)
- version restore creates before_restore

### Tasks
- status transition validator
- assignment constraints
- board ordering position updates

### Comments
- thread creation + replies
- mention parsing and notifications
- edit window enforcement
- resolve thread permissions

### Notifications
- unread count correct
- preferences respected
- email job queued

### Search
- workspace isolation in search results
- FTS query returns expected items
