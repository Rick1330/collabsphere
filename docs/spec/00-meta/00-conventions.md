### Conventions Used

- **§** references a section number (e.g., §5.3 = Task Management)
- **FREQ-XXX** references a functional requirement
- **NFR-XXX** references a non-functional requirement
- **BR-XXX** references a business rule
- **ADR-XXX** references an architecture decision record
- **v1** = initial release scope
- **v1.1** = fast-follow release
- **v2+** = future scope (designed for, not built yet)
