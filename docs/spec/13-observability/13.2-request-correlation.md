## §13.2 Request Correlation (Request ID)

### §13.2.1 Requirement
Every incoming HTTP request and WebSocket connection must have a unique `requestId`.

### §13.2.2 Implementation
- API:
  - middleware adds `X-Request-Id` if missing
  - include `requestId` in all response meta and errors
- Workers:
  - propagate a jobId + requestId if available
- Socket.IO:
  - assign `connectionId` and log with userId
