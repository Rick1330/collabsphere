## §13.3 Structured Logging

### §13.3.1 Format
Logs must be JSON objects (one per line).

### §13.3.2 Required Fields (API Logs)
| Field | Required | Notes |
|------|----------|------|
| `timestamp` | ✅ | ISO UTC |
| `level` | ✅ | info/warn/error |
| `message` | ✅ | short |
| `requestId` | ✅ | correlation |
| `method` | ✅ | GET/POST |
| `path` | ✅ | endpoint |
| `statusCode` | ✅ | response status |
| `durationMs` | ✅ | request latency |
| `userId` | if auth | |
| `workspaceId` | if scoped | |
| `errorCode` | if error | from taxonomy |
| `ip` | ✅ | |
| `userAgent` | ✅ | |

Example:
```json
{
  "timestamp": "2025-07-17T12:00:00Z",
  "level": "info",
  "message": "request_completed",
  "requestId": "req_abc123",
  "method": "POST",
  "path": "/api/v1/workspaces/123/tasks",
  "statusCode": 201,
  "durationMs": 142,
  "userId": "u-uuid",
  "workspaceId": "w-uuid",
  "ip": "203.0.113.10",
  "userAgent": "Mozilla/5.0"
}
```
