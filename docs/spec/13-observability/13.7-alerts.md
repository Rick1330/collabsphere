## §13.7 Alerts (v1 minimum)

| Alert | Condition | Severity |
|------|-----------|----------|
| High API error rate | 5xx > 2% for 5 min | P1 |
| DB unreachable | connection failures > threshold | P0 |
| Collaboration persist failures | > 10/min | P1 |
| Queue backlog growing | depth > 100 for 10 min | P2 |
| Email failure spike | failures > 5% in 10 min | P2 |
| Auth attack suspicion | login_failed spikes from same IP | P1 |

Alerts must include:
- requestId samples
- recent deploy version
- top endpoints impacted
