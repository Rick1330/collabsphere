## §13.6 Dashboards (v1 minimum)

### Operational Dashboard
Panels:
- API requests per minute
- API latency p50/p95/p99
- Error rate (4xx/5xx)
- DB latency and connection pool utilization
- Socket connections count
- Collaboration connections count
- Queue depth by queue
- Email job failures

### Product Health Dashboard
Panels:
- new user registrations/day
- workspaces created/day
- documents created/day
- tasks created/day
- notifications sent/day
- top error codes
