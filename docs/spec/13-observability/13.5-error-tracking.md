## §13.5 Error Tracking

### §13.5.1 Requirement
Capture unhandled exceptions with stack traces in a dedicated error tracking system (Sentry or equivalent).

### §13.5.2 Rules
- Attach requestId, userId, workspaceId
- Never attach sensitive payloads (passwords, tokens)
- Group errors by stack trace signature
