## §13.4 Metrics (Minimum Set)

### §13.4.1 API Metrics
- `api.requests.count` (counter, labels: method, route, status)
- `api.latency.ms` (histogram, labels: method, route)
- `api.errors.count` (counter, labels: code, route)

### §13.4.2 Database Metrics
- `db.query.latency.ms` (histogram, labels: operation/table)
- `db.pool.active` (gauge)

### §13.4.3 Realtime Metrics
- `socket.connections.active` (gauge)
- `socket.events.emitted.count` (counter, labels: event)
- `collab.connections.active` (gauge)
- `collab.persist.failures.count` (counter)

### §13.4.4 Queue Metrics
- `queue.jobs.enqueued.count` (counter, labels: queueName)
- `queue.jobs.failed.count`
- `queue.jobs.processing.count` (gauge)
- `queue.jobs.latency.ms` (histogram)
