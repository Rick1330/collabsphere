## §14.5 CI Pipeline (GitHub Actions)

### §14.5.1 Required Checks (PR)
- Typecheck (TS)
- Lint
- Unit tests
- Integration tests (DB required)
- Build web + api + collab + worker

### §14.5.2 Optional (P2)
- Playwright E2E tests on staging preview
- Lighthouse CI for performance regression

### Example CI stages
1. Install dependencies
2. Lint
3. Typecheck
4. Unit tests
5. Integration tests (bring up Postgres/Redis via services)
6. Build
