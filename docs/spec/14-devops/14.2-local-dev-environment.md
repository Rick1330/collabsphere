## §14.2 Local Development Environment (Authoritative)

### §14.2.1 Prerequisites
- Node.js 20 LTS
- pnpm 9.x
- Docker Desktop (or Docker Engine + Compose)
- Git

### §14.2.2 One-command local startup
Local dev should start with:

```bash
pnpm install
pnpm dev
```

Where `pnpm dev` starts:
- `apps/web` (static web bootstrap served from `src/index.html`)
- `apps/api` (NestJS REST + Socket.IO)
- `apps/collab` (Hocuspocus)
- `apps/worker` (BullMQ workers)
- Docker services:
  - PostgreSQL
  - Redis
  - MinIO (optional v1.1)
  - MailHog (or similar email capture) for local

### §14.2.3 Docker Compose (v1 minimum)
Services:
- `postgres`
- `redis`
- `minio` (optional)
- `mailhog` (optional)

### Example docker-compose.yml (conceptual)
```yaml
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_USER: collab
      POSTGRES_PASSWORD: collab
      POSTGRES_DB: collabsphere
    ports:
      - "5432:5432"

  redis:
    image: redis:7
    ports:
      - "6379:6379"
```
