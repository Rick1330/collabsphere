## §14.6 Deployment Strategy (v1)

### §14.6.1 Recommended v1 Hosting
- Frontend: Vercel or similar
- Backend services: single VPS (Docker Compose) OR Railway/Fly.io
- Database: managed Postgres (Supabase/Railway) OR VPS Postgres
- Redis: managed Redis or VPS Redis

### §14.6.2 Deployment Units
- `web` deployed separately
- `api`, `collab`, `worker` deployed together (same network)

### §14.6.3 Zero-downtime (v1 scope)
- Not required for v1 but recommended:
  - rolling restart for API
  - collab server reconnect handled automatically
