## §6.8 Usability Requirements

### NFR-U01 — First-Time Usability
- A new user must be able to:
  - create/join a workspace
  - create a document
  - create a task
  within **10 minutes** without reading documentation.

### NFR-U02 — Consistent UI States
Every page handles:
- loading state
- empty state
- error state
- loaded state
(see §3.7)
