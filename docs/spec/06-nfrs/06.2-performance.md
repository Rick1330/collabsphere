## §6.2 Performance Requirements

### NFR-P01 — UI Responsiveness (Web)

**Requirement**
- Core pages must load fast enough to maintain user flow.

**Targets**
- Dashboard initial load (LCP): **< 2.5s** on 4G throttled (Lighthouse)
- Workspace home load: **< 2.5s**
- Documents list/tree load: **< 2.0s**
- Task board initial load: **< 2.0s**

**Measurement**
- Lighthouse CI for LCP/TBT
- Real user monitoring (RUM) events (v1.1+)

---

### NFR-P02 — API Latency

**Targets**
- p50 latency: **< 200ms**
- p95 latency: **< 500ms**
- p99 latency: **< 1000ms**

**Scope**
- Applies to all REST endpoints except export/download endpoints (which may be async).

**Measurement**
- Server metrics (histograms)
- Load test baseline before launch

---

### NFR-P03 — Real-Time Collaboration Latency

**Targets**
- Document edit propagation: **< 500ms** end-to-end under normal network conditions
- Presence/cursor updates: **< 500ms**

**Measurement**
- Client-side telemetry (optional)
- Collaboration server metrics (broadcast latency histogram)

---

### NFR-P04 — Search Latency

**Targets**
- Workspace-scoped search: **< 500ms**
- Global search: **< 800ms**

**Measurement**
- DB query timing logs + metrics
- Ensure PostgreSQL FTS indexes exist

---

### NFR-P05 — Task Board Interaction Performance

**Targets**
- Drag-and-drop operation must feel instant:
  - UI response: **< 100ms**
  - API confirmation: **< 500ms**

**Strategy**
- Optimistic UI
- Background retry on transient failure
- Lazy-load large columns (virtualization)

---
