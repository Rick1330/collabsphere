## §6.9 Maintainability Requirements

### NFR-M01 — Modular Architecture
- Use modular monolith:
  - clear module boundaries
  - no cross-module DB access except via service layer
- Shared types in shared package

### NFR-M02 — Configuration Management
- All environment configuration via:
  - `.env` + typed config loader
- No hardcoded secrets

### NFR-M03 — API Consistency
- Standard response envelope:
  - `{ data, meta }` for success
  - `{ error }` for failure
- Standard pagination format
- Standard error taxonomy (see §12 later)
