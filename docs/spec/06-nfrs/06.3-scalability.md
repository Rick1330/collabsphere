## §6.3 Scalability Requirements

### NFR-SC01 — Concurrent Users (v1 target)

**Targets**
- Platform supports **500 concurrent active users**
- Supports **10 concurrent editors per document**
- Supports **50 members per workspace** (default limit)

**Notes**
- “Concurrent active user” = user performing actions every 30–60s, not idle.

---

### NFR-SC02 — Horizontal Scaling

**Requirement**
- The backend must support horizontal scaling for:
  - REST API nodes
  - Realtime/collaboration nodes
  - Workers (email/export)

**Implementation constraints**
- Use stateless API servers
- Store sessions/refresh tokens in DB
- Use Redis for:
  - rate limiting
  - socket adapter/presence coordination (if scaling realtime)

---

### NFR-SC03 — Data Volume (v1 guidance)

Per workspace:
- up to 500 documents
- up to 2,000 tasks
- up to 10,000 comments
- up to 5GB files (v1.1+)

The system must remain responsive within these bounds.
