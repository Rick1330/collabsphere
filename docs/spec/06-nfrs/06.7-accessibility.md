## §6.7 Accessibility Requirements

### NFR-A11Y01 — Compliance Target
- WCAG 2.1 AA target (not just Level A)

### NFR-A11Y02 — Keyboard-only Support
- Entire app navigable by keyboard:
  - command palette
  - sidebar navigation
  - task board alternative to drag-drop
  - modals with focus trap

### NFR-A11Y03 — Screen Reader Support
- Semantic HTML
- ARIA labels on icon buttons
- Live region announcements for:
  - notification arrival
  - task moved
  - document saved
