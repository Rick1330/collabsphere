## §6.10 Observability Requirements

### NFR-O11Y01 — Request Tracing
- Every request must have a `requestId`
- Included in:
  - response headers
  - logs
  - error responses

### NFR-O11Y02 — Structured Logging
- JSON structured logs
- Include:
  - requestId
  - userId (if authenticated)
  - workspaceId (if scoped)
  - latency
  - status code
  - error code (if any)

### NFR-O11Y03 — Metrics
Minimum metrics:
- API latency histograms
- error rates
- realtime connection count
- queue depth
- DB query latency (sampled)
