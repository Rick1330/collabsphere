## §6.12 Verification & Testability

Each NFR must be verifiable:

| NFR Category | Verification Method |
|-------------|----------------------|
| Performance | Lighthouse CI + load tests |
| Security | OWASP scan + RBAC integration tests |
| Reliability | chaos tests (P2), dependency failure simulation |
| Accessibility | automated audits + manual keyboard testing |
| Observability | dashboard + alerts present; logs contain requestId |
